## 二、引用原则

1. 可变数据（人口、面积、产量、贸易额等）在文中标注来源或年份，不使用无出处的精确数字。
2. 不同机构口径存在差异时，说明差异而不强行给出单一数值。
3. 河流长度、大洲面积、储量等指标因测量方法不同存在多个数据，本站优先给出范围或注明口径。
4. 中文教材与译著若无法确认具体版次，在参考资料中标注“待核查”。
5. 不编造论文、书籍、作者、数据与参考文献。

## 三、事实 / 观点 / 推论 / 争议

文章中使用以下约定：

- **事实**：有多源可核查数据或广泛观测支持的表述。
- **学术观点**：学界较通行但仍存在模型差异的解释，用“通常认为”“研究表明”等表述。
- **推论**：基于已知机制的合理延伸，明确标注为推论，例如“未来是否会形成新大洋”。
- **争议**：存在不同研究结论的问题，明确写出“仍有讨论”“尚无定论”，不选择一侧作为定论。
